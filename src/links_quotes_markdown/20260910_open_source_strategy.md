Open source is usually discussed in terms of code, reuse and avoiding lock-in. This adds another dimension: opening a layer can be a way for several weaker parties to stop one stronger party owning something they all depend on. Android is a useful warning too. Open code does not automatically keep power distributed; governance, standards and the surrounding dependencies still matter.
