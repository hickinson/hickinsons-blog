The interesting part of agents isn't simply that software can now do more on its own. It is deciding what we're prepared to delegate, how that work is constrained, how we know whether it succeeded and where human judgement still belongs.

I'm drawn to systems that make authority, evidence and failure visible; that separate doing from judging; and that treat verification as part of the design rather than something added when the agent gets things wrong.

Repos I'm keeping close: [Microsoft Agent Framework](https://github.com/microsoft/agent-framework), [Superpowers](https://github.com/obra/superpowers), [Agent Skills](https://github.com/addyosmani/agent-skills), [smalltask](https://github.com/gabrielmoffa/smalltask), [ArcKit](https://github.com/tractorjuice/arc-kit), [Paperclip](https://github.com/paperclipai/paperclip) and the [Fabric Data Agent testing template](https://github.com/clientfirsttech/fabric-data-agent-testing-template).
