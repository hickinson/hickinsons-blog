Organisations contain lots of language but surprisingly little shared meaning. Different professions use different words, and sometimes the same words for different things. Metadata becomes more interesting when it is treated as captured context: what something means, why it exists, who understands it and how it connects. A catalogue can be part of an organisation learning how to explain itself.
