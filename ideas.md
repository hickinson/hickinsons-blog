# Editorial ideas

Use the **Editorial idea** issue form to capture new observations, questions, sources and experiences. The assisted workflow is documented in [AUTOMATION.md](AUTOMATION.md), with editorial standards in [EDITORIAL.md](EDITORIAL.md).

The former backlog in this file was migrated to GitHub Issues during Stage 4. This file is intentionally not a second source of editorial state.
